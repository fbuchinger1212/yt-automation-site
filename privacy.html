Privacy Policy

Last updated: October 25, 2026

yt-automation ("the app") is a private tool operated by Felix Buchinger ("I"). It runs only on my own computer and is used only to manage YouTube channels that I own. This policy explains which data the app accesses and how it is handled.

1. Data the app accesses

When I sign in with Google, the app receives access to my YouTube account through the YouTube API Services with these permissions:

  • youtube.upload – to upload videos and set their title, description, tags and publication time.
  • youtube.readonly – to read the channel name, channel ID, profile picture and the list of my own uploads (to avoid duplicate uploads).

The app does not access e-mail, contacts, files, payment data or any data of other YouTube users.

2. How the data is used

The data is used only to upload and schedule my own videos and to show which channel is connected. It is not used for advertising, profiling, or any other purpose.

3. Storage

The Google access token is stored only locally on my computer in a protected folder. No data is sent to any server other than Google's own APIs. There is no database, no analytics and no tracking.

4. Sharing

Data obtained through Google APIs is not sold, shared with, or transferred to any third party.

5. Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. YouTube API Services

The app uses YouTube API Services. Please also see the Google Privacy Policy and the YouTube Terms of Service.

7. Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions or via the Google security settings page. Deleting the local token file removes all stored data immediately.
